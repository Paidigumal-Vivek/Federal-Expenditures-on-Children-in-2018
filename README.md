# Federal Expenditures on Children in 2018

## Overview
This project analyzes federal expenditures on children in the United States for the year 2018. The primary objective is to evaluate and redesign a poorly constructed graph to improve clarity and accuracy in data representation using visualization techniques. The analysis emphasizes effective data visualization principles and employs software tools to enhance graphical communication.

## Project Objectives
- Identify and analyze a poorly designed graph.
- Improve clarity and accuracy in data representation.
- Use Tableau for data visualization.
- Present a redesigned graph with enhanced usability and interpretability.

## Data Source
The data for this project is obtained from the website [Budgeting for the Children: Where Does the Money Go?](https://howmuch.net/sources/us-federal-expenditures-children-2018). The dataset provides insights into government spending across various categories related to child welfare, including health, education, nutrition, and income security.

## Tools and Technologies Used
- **Excel**: Data preprocessing and structuring.
- **Tableau**: Data visualization and graph redesign.
- **Python (optional)**: Data analysis and processing.

## Project Workflow
1. **Identify the Bad Graph**: Assess the original graph's strengths and weaknesses.
2. **Data Cleaning & Preparation**: Extract and structure the data into a CSV format for analysis.
3. **Graph Redesign**:
   - Improve clarity and readability.
   - Use appropriate color schemes.
   - Enhance data interpretation and insights.
4. **Cognitive Testing**: Validate the effectiveness of the redesigned graph through a set of analytical questions.
5. **Final Visualization & Interpretation**: Present the new graph and compare it with the original visualization.

## Challenges Faced
- No year-over-year comparison was provided in the original graph.
- Data labels were overlapping, requiring separate visualization approaches.
- Simplification was necessary without losing critical details.

## Key Findings & Improvements
- The redesigned graph provides a clearer representation of categories and subcategories.
- The visualization effectively highlights spending distribution and year-over-year changes.
- The use of distinct colors and bar charts ensures improved readability and understanding.

## Alternative Approaches
While the bar graph was chosen for its simplicity and clarity, alternative visualization techniques such as pie charts or heat maps could be explored in future iterations.
